Specificity War Playground

Four real CSS rules of very different specificity all target the same paragraph's color. Assign each one to a declared layer (or leave it unlayered), reorder the layers, toggle !important per rule — a real <style> tag is rewritten on every change, so a real browser decides the winner, not a simulation.

Declared Layer Order (lowest → highest priority)

    Layers declared later win, for normal (non-important) rules. Move a layer down to raise its priority — every rule currently assigned to it inherits the new priority instantly.
