Rolling Back with revert-rule

The heading below has its font-weight set by the last rule in the cascade stack. Choose the keyword that rule uses and read the computed weight back with getComputedStyle(). Each keyword rolls back to a different place.

Your browser doesn't support revert-rule, so it drops that declaration and the result below is only what the remaining rules give. It's supported in Chrome and Edge 148, Firefox 150 and Safari 27 or later.
