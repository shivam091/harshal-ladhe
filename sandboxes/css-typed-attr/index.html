HTML Attributes as CSS Values with Typed attr()

The controls only change HTML attributes. Typed attr() reads each one as a percentage, colour, integer or angle, and CSS does the rest — no inline styles, no custom properties set from JavaScript.

This browser only supports the classic attr() inside content, so every component falls back to its default styles. The percentage label still updates, because that part uses the classic form.

attr(data-progress %)

attr(data-colour type(<color>))
