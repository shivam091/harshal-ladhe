Acquire and Release with AsyncDisposableStack

A task takes a lock, opens a file and starts an autosave timer, then does its work. Every resource goes onto an AsyncDisposableStack, which releases them in reverse order however the task ends. Make the task throw part-way, or make closing the file throw as well, and watch what gets released and which error comes out.

Your browser doesn't support DisposableStack and AsyncDisposableStack. They're supported in Chrome and Edge 134, Firefox 141 and Node 24 or later. Safari only has them in Technology Preview.
