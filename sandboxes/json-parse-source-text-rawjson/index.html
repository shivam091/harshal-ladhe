Large numbers through JSON, without losing digits

A plain JSON.parse() rounds integers above Number.MAX_SAFE_INTEGER. The reviver's context.source and JSON.rawJSON() keep every digit, in and out.

This browser doesn't support JSON.parse source text access or JSON.rawJSON(), so only the plain parse can run.

    2. JSON.parse(json, reviveBigInts)

      3. JSON.stringify(result, replaceBigInts)
