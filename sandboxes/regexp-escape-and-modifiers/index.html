Searching with a Pattern Built from User Input

Type a search term and every match in the text is highlighted. With Escape input off, the term goes into new RegExp() as it is, so ., +, ( and * act as regex syntax. Turn it on and RegExp.escape() makes them literal. Below that, try inline modifiers and duplicate named groups on your own test strings.

Your browser doesn't support everything this playground uses. RegExp.escape() needs Chrome and Edge 136, Firefox 134, Safari 18.2 or Node 24; inline modifiers need Chrome and Edge 125, Firefox 132, Safari 26 or Node 23; duplicate named groups need Chrome and Edge 125, Firefox 129, Safari 17 or Node 23.
