Native CSS Nesting

Hover, focus (click into) the card, or toggle .active — every rule styling it is natively nested, no preprocessor.

Nested Card

This card's hover, focus, active, and child-element styles are all defined inside one nested rule.

.card {
  border: 1px solid #333;

  &:hover {
    border-color: royalblue;
  }

  &:focus-within {
    outline: 2px solid royalblue;
  }

  &.active {
    background: royalblue;
  }

  .card-title {
    font-weight: 700;
  }

  &.active .card-title,
  &.active .card-body {
    color: white;
  }
}
