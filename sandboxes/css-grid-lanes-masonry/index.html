Masonry with display: grid-lanes

Twelve cards of different heights, numbered in HTML order. Compare how grid lanes, a regular grid and multi-column layout arrange them, and watch where each number lands.

This browser doesn't support display: grid-lanes yet, so the grid lanes option falls back to multi-column layout. In Chromium you can turn on Experimental Web Platform features in chrome://flags to try it.
