Accordion — animates to auto, no JS measuring

Every panel's height transitions between 0 and auto directly — no scrollHeight read, no grid-rows hack.

`interpolate-size: allow-keywords` lets `height`/`width` transition to and from `auto`, `min-content`, and `fit-content` directly — values that were never animatable before this.

A JS `scrollHeight` measurement, a `max-height: 9999px` guess, or a `grid-template-rows: 0fr → 1fr` trick — every prior workaround for animating to a size CSS couldn't otherwise compute in advance.

No — unlike the `max-height` guess trick, the transition always targets the content's REAL height, however long it is, with no risk of a longer answer getting clipped or a short one animating for too long.
