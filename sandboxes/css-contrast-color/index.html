Readable Text on Any Background with contrast-color()

Pick a background colour. The text on it is set with color: contrast-color(var(--bg)), so the browser chooses white or black. The readout compares that choice with the WCAG 2 contrast ratio against each, worked out in JavaScript.

Your browser doesn't support contrast-color(), so the text below uses a fixed white fallback. It's supported in Chrome and Edge 147, Firefox 146 and Safari 26 or later. The WCAG ratios in the readout still work.
