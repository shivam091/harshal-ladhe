A Responsive Speech Bubble with shape()

Both bubbles use the same outline: rounded corners drawn with arc and a curved tail drawn with curve. The top one is a shape() written in %, rem and calc(var(--tail) …). The bottom one is the same outline as a path(), which only understands pixels.

This browser doesn't support shape() yet, so the top bubble falls back to a straight-edged polygon() with square corners and a pointed tail.
