Confetti from Pure CSS random()

Every piece below is identical HTML. Its position, size, rotation and colour come from random() in the stylesheet — JavaScript only adds pieces and switches modes.

This browser doesn't support CSS random() yet, so the confetti uses the fallback pattern from the tutorial: JavaScript writes one random number per custom property, and CSS scales it. In Chromium you can turn on Experimental Web Platform features in chrome://flags to try the real thing.
