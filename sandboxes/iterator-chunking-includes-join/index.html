Chunks, Windows, includes() and join()

Type a comma-separated list and a size. chunks(n) splits it into groups that don't overlap, windows(n) slides over it one value at a time, and the windows feed a moving average. Below, includes() shows how far it reads before it stops, and join() builds a string.

    Methods marked "fallback" are missing in this browser, so those results come from the hand-written fallbacks in the tutorial, which follow the same rules. chunks() and windows() are native in Firefox 154; join() in Chrome and Edge 153 and Firefox 154; includes() in Chrome and Edge 154 and Firefox 154. Safari has all four in Technology Preview.
