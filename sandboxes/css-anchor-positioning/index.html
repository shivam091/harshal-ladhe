A Tooltip That Follows Its Anchor

Move the button around the stage with the sliders. The tooltip is placed with position-area and flips with position-try-fallbacks when it would overflow — no JavaScript measures anything.

This browser doesn't support CSS anchor positioning, so the tooltip sits in the stage's top-left corner instead of next to the button.
