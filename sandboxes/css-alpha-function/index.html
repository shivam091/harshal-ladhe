Translucent Colours with alpha()

Choose an origin colour and an alpha. The first swatch sets the alpha with alpha(from var(--c) / var(--a)) and the second scales the origin's own alpha with calc(alpha * n). The other two use the older color-mix() and rgb(from ...) routes, and the readout shows what each one resolved to.

Your browser doesn't support alpha(), so the two alpha() swatches use a color-mix() fallback and look the same as the third. It's supported from Chrome and Edge 152, Firefox 155 and Safari 27.
