Collecting a Paginated API with Array.fromAsync()

An async iterable hands back one page of products every 300ms, like a paginated API. Array.fromAsync() waits for every page and collects them into one array. Make page 2 fail to see what happens to the pages before it, then compare running five requests one after another with running them all at once.

Your browser doesn't support Array.fromAsync(). It's supported in Chrome and Edge 121, Firefox 115, Safari 16.4 and Node 22 or later.
