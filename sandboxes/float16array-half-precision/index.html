Storing Numbers in 64, 32 and 16 Bits

Enter some numbers and each one is written into a Float64Array, a Float32Array and a Float16Array, then read back. The table shows what each array actually stored, how far the half-precision value is from what you typed, and how many bytes each array needs. Pick a value to see its 16 bits split into sign, exponent and mantissa.

Your browser doesn't support Float16Array, Math.f16round() and DataView.prototype.getFloat16(). They're supported in Chrome and Edge 135, Firefox 129, Safari 18.2 and Node 24 or later.
