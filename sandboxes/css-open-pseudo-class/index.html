One Pseudo-Class for Everything That Opens

An accordion, a dialog and a select, each styled with :open. The readout asks every element element.matches(":open") and lists the ones that match right now.

Your browser doesn't support :open, so the open-state styles below won't apply and the readout falls back to the [open] attribute, which can't see the select. :open is supported in Chrome and Edge 133, Firefox 136 and Safari 26.5 or later.
