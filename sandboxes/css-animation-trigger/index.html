Scroll-triggered reveals, no JavaScript observer

Each card defines its own --reveal trigger with timeline-trigger and plays a 600ms animation when it's fully in view. Scroll the list, then scroll back up.

This browser doesn't support scroll-triggered animations, so the cards are shown without animating.

animation-trigger: --reveal play-forwards play-backwards;
