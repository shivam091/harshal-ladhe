## Introduction

A tick that draws itself on is a small, clear "it worked" signal after a payment, a saved form, or a finished upload. It doesn't need a Lottie file or a GIF. It's **one `<path>` and about eight lines of CSS**.

The path is given a normalised length with `pathLength="100"`, hidden with a dash offset, and drawn on by animating `stroke-dashoffset` from `100` to `0`.

<RainbowDivider />

## The Code

<SvgSnippet>
{`
  <svg class="svg-check" viewBox="0 0 100 100" width="72" height="72" role="img" aria-label="Success">
    <style>
      .svg-check path {
        stroke-dasharray: 100;
        stroke-dashoffset: 100;
        animation: svg-check-draw 0.5s ease-out 0.2s forwards;
      }

      @keyframes svg-check-draw {
        to {
          stroke-dashoffset: 0;
        }
      }

      @media (prefers-reduced-motion: reduce) {
        .svg-check path {
          animation: none;
          stroke-dashoffset: 0;
        }
      }
    </style>
    <path d="M22 52 L42 72 L80 30" fill="none" stroke="#14b8a6" stroke-width="10" stroke-linecap="round" stroke-linejoin="round" pathLength="100" />
  </svg>
`}
</SvgSnippet>

<RainbowDivider />

## How It Works

1. The tick is a single `<path>` with two straight segments: down to the bottom of the tick, then up to the right.
2. `pathLength="100"` tells the browser to treat the path as **100 units long**, so you never have to measure it.
3. `stroke-dasharray: 100` turns the stroke into one dash as long as the whole path, followed by a gap of the same length.
4. `stroke-dashoffset: 100` shifts that pattern along by a full dash, so the gap covers the path and nothing is visible.
5. The animation moves the offset to `0`, sliding the dash back into place from the start of the path. It traces the short stroke first, then the long one, just like a hand-drawn tick.
6. `forwards` keeps the final frame, so the tick stays drawn. The `0.2s` delay lets the surrounding message appear first, and during the delay the base `stroke-dashoffset: 100` keeps the tick hidden.

## Variant: Circle First, Then the Tick

For a stronger success state, draw a circle around the tick first. Both shapes use the same keyframes. The tick's `animation-delay` is a little shorter than the circle's duration, so the two strokes overlap slightly and read as one motion. A small scale "pop" at the end finishes it off.

<SvgSnippet>
{`
  <svg class="svg-check-circle" viewBox="0 0 100 100" width="96" height="96" role="img" aria-label="Success">
    <style>
      .svg-check-circle {
        animation: svg-check-circle-pop 0.3s ease-out 1s;
      }

      .svg-check-circle circle,
      .svg-check-circle path {
        stroke-dasharray: 100;
        stroke-dashoffset: 100;
        animation: svg-check-circle-draw 0.6s ease-in-out forwards;
      }

      .svg-check-circle path {
        animation-duration: 0.4s;
        animation-delay: 0.55s;
      }

      @keyframes svg-check-circle-draw {
        to {
          stroke-dashoffset: 0;
        }
      }

      @keyframes svg-check-circle-pop {
        50% {
          scale: 1.08;
        }
      }

      @media (prefers-reduced-motion: reduce) {
        .svg-check-circle,
        .svg-check-circle circle,
        .svg-check-circle path {
          animation: none;
          stroke-dashoffset: 0;
        }
      }
    </style>
    <circle cx="50" cy="50" r="44" fill="none" stroke="#14b8a6" stroke-width="6" stroke-linecap="round" pathLength="100" transform="rotate(-90 50 50)" />
    <path d="M30 52 L44 66 L72 36" fill="none" stroke="#14b8a6" stroke-width="7" stroke-linecap="round" stroke-linejoin="round" pathLength="100" />
  </svg>
`}
</SvgSnippet>

- **The circle** starts at 3 o'clock by default. `transform="rotate(-90 50 50)"` turns it around its centre so it draws from 12 o'clock.
- **The tick** starts at `0.55s`, just before the circle finishes at `0.6s`, and is drawn by `0.95s`.
- **The pop** runs on the outer `<svg>` at `1s`. It has no `forwards`, so it returns to normal size afterwards. Scaling the `<svg>` itself works without extra setup, because an element's `transform-origin` defaults to its centre.

## Example Usage

Put the tick inside the success message itself. The animation runs when the element is inserted or shown, so rendering the message is all it takes. The message is announced through `role="status"`, which makes the icon decorative:

<CodeBlock language="html">
{`
  <div class="toast" role="status">
    <svg class="svg-check" viewBox="0 0 100 100" width="24" height="24" aria-hidden="true">
      <path d="M22 52 L42 72 L80 30" fill="none" stroke="currentColor" stroke-width="10"
            stroke-linecap="round" stroke-linejoin="round" pathLength="100" />
    </svg>
    Payment received
  </div>
`}
</CodeBlock>

To play it again on an element that is already on the page, restart its CSS animations, including those on child elements:

<CodeBlock language="js">
{`
  function replay(svg) {
    for (const animation of svg.getAnimations({ subtree: true })) {
      animation.cancel();
      animation.play();
    }
  }
`}
</CodeBlock>

## Notes & Tips

- **Show the final state for reduced motion:** with `prefers-reduced-motion: reduce`, the animation is removed and `stroke-dashoffset` is set to `0`, so the tick is simply there. Don't just remove the animation, or the base offset of `100` leaves it invisible.
- **Pick the right label:** use `role="img"` with `aria-label` when the tick is the only sign of success. When text next to it already says what happened, mark the SVG `aria-hidden="true"` and put `role="status"` on the message so screen readers announce it.
- **Keep it short:** about half a second for the tick is enough. A longer draw makes a fast action feel slow.
- **Change the shape freely:** because of `pathLength="100"`, you can redraw the tick, move its points, or resize the `viewBox` without touching the CSS.
- **Namespace the class and keyframes:** a `<style>` inside an inline SVG applies to the **whole page**, so `.svg-check` and `svg-check-draw` should be names nothing else uses. You can also move the rules into your stylesheet.
- **Browser support:** animating `stroke-dashoffset` and the `pathLength` attribute both work in all current browsers. The standalone `scale` property used for the pop is also supported everywhere current; use `transform: scale(1.08)` in the keyframes for older browsers.

## Frequently Asked Questions

<Details summary="Why does the tick draw from the short stroke to the long one?">
  A stroke is drawn in the order of the path data. The path starts at the left end (`M22 52`), goes down to the corner,
  then up to the right, and the dash slides in from the start. Reverse the points, or animate the offset from `-100` to
  `0`, to draw it from the other end.
</Details>

<Details summary="Why is the tick invisible when I remove the animation?">
  The hidden state comes from the base `stroke-dashoffset: 100`, not from the animation. Without the animation nothing
  moves the offset to `0`. Set `stroke-dashoffset: 0` wherever you turn the animation off, as the reduced-motion rule
  does.
</Details>

<Details summary="How do I make the tick appear only after an action?">
  Put the animation behind a class, for example `.is-done .svg-check path { animation: ... }`, and add the class when
  the action succeeds. Or insert the SVG into the page at that moment. CSS animations start when the element starts
  matching the rule.
</Details>

<Details summary="Can I use it for a cross or another icon?">
  Yes. Any stroked path works the same way. A cross is two separate lines, so draw it as two paths, each with
  `pathLength="100"`, and give the second one an `animation-delay`, as the circle variant does. Two paths are more
  predictable than one path with two subpaths, where the dash pattern has to span a jump.
</Details>

## Key Takeaway

Give one tick-shaped `<path>` `pathLength="100"`, hide it with `stroke-dasharray: 100` and `stroke-dashoffset: 100`, and animate the offset to `0` with `forwards`. Draw a circle first with an `animation-delay` on the tick for a fuller success state, and set the offset straight to `0` for reduced motion so the tick is always visible.
