## Introduction

Loading spinners are often a GIF, an icon font glyph, or a stack of nested `<div>`s with borders. An SVG spinner can be smaller and simpler: **one `<circle>`, no JavaScript, and about ten lines of CSS**. Its stroke is cut into a single arc with a dash pattern, and CSS rotates it.

Because it's a vector stroke, it stays sharp at any size, takes its colour from `currentColor`, and its thickness is one attribute.

<RainbowDivider />

## The Code

<SvgSnippet>
{`
  <svg class="svg-spinner" viewBox="0 0 50 50" width="48" height="48" role="img" aria-label="Loading">
    <style>
      .svg-spinner {
        animation: svg-spinner-rotate 0.9s linear infinite;
      }

      @keyframes svg-spinner-rotate {
        to {
          rotate: 360deg;
        }
      }

      @media (prefers-reduced-motion: reduce) {
        .svg-spinner {
          animation-duration: 3s;
        }
      }
    </style>
    <circle cx="25" cy="25" r="20" fill="none" stroke="currentColor" stroke-width="5" stroke-linecap="round" pathLength="100" stroke-dasharray="25 75" />
  </svg>
`}
</SvgSnippet>

<RainbowDivider />

## How It Works

1. `pathLength="100"` tells the browser to treat the circle's outline as **100 units long**, whatever its real circumference (`2πr ≈ 125.66` here). Dash values become percentages of the circle.
2. `stroke-dasharray="25 75"` draws a 25-unit dash followed by a 75-unit gap. They add up to 100, so there's exactly one arc, a quarter of the circle.
3. `stroke-linecap="round"` rounds the ends of the arc.
4. The `@keyframes` rule rotates the whole `<svg>` from `0` to `360deg` with `linear` timing, so the speed is constant and there's no pause at the end of each turn.
5. The rotation is applied to the outer `<svg>` element, and an element's `transform-origin` defaults to its centre, so it turns around its own middle with nothing extra to set.

## Variant: A Growing and Shrinking Arc

For the Material-style spinner, where the arc grows and shrinks while it rotates, animate the dash pattern as well. A gap of `200` is longer than the whole circle, so there's still only one dash, however long it gets:

<SvgSnippet>
{`
  <svg class="svg-spinner-grow" viewBox="0 0 50 50" width="48" height="48" role="img" aria-label="Loading">
    <style>
      .svg-spinner-grow {
        animation: svg-spinner-grow-rotate 2s linear infinite;
      }

      .svg-spinner-grow circle {
        animation: svg-spinner-grow-dash 1.5s ease-in-out infinite;
      }

      @keyframes svg-spinner-grow-rotate {
        to {
          rotate: 360deg;
        }
      }

      @keyframes svg-spinner-grow-dash {
        0%   {
          stroke-dasharray: 1 200;
          stroke-dashoffset: 0;
        }

        50%  {
          stroke-dasharray: 75 200;
          stroke-dashoffset: -25;
        }

        100% {
          stroke-dasharray: 75 200;
          stroke-dashoffset: -99;
        }
      }

      @media (prefers-reduced-motion: reduce) {
        .svg-spinner-grow,
        .svg-spinner-grow circle {
          animation-duration: 4s;
        }
      }
    </style>
    <circle cx="25" cy="25" r="20" fill="none" stroke="#6366f1" stroke-width="5" stroke-linecap="round" pathLength="100" />
  </svg>
`}
</SvgSnippet>

- **0% → 50%:** the dash grows from a dot to three-quarters of the circle, and moving the offset back by 25 makes its tail move a little too.
- **50% → 100%:** the dash keeps its length, but the offset moves it past the end of the path. Only its last unit is still visible, which matches the dot the next loop starts with, so the loop is seamless.
- The rotation and dash animations have different durations, so the arc starts each loop at a different angle and doesn't look repetitive.

## Example Usage

Give the SVG a colour through `color` and its size through CSS, so one spinner works in buttons, cards, and page-level loading states:

<CodeBlock language="css">
{`
  .button .svg-spinner {
    inline-size: 1em;
    block-size: 1em;
    color: inherit;
  }

  .page-loader .svg-spinner {
    inline-size: 3rem;
    block-size: 3rem;
    color: var(--color-accent);
  }
`}
</CodeBlock>

To add a faint track behind the arc, put a second circle before it with the same geometry, a low `stroke-opacity`, and no dash pattern. Only the arc needs the dash pattern, so the rotation still turns the whole SVG:

<SvgSnippet>
{`
  <svg class="svg-spinner-track" viewBox="0 0 50 50" width="48" height="48" role="img" aria-label="Loading">
    <style>
      .svg-spinner-track {
        color: #6366f1;
        animation: svg-spinner-track-rotate 0.9s linear infinite;
      }

      @keyframes svg-spinner-track-rotate {
        to {
          rotate: 360deg;
        }
      }

      @media (prefers-reduced-motion: reduce) {
        .svg-spinner-track {
          animation-duration: 3s;
        }
      }
    </style>
    <circle cx="25" cy="25" r="20" fill="none" stroke="currentColor" stroke-width="5" stroke-opacity="0.2" />
    <circle cx="25" cy="25" r="20" fill="none" stroke="currentColor" stroke-width="5" stroke-linecap="round" pathLength="100" stroke-dasharray="25 75" />
  </svg>
`}
</SvgSnippet>

## Use Cases

- **Button loading states**, such as "Saving…", sized in `em` to match the label.
- **Lazy-loaded sections** and infinite-scroll footers.
- **Full-page or route-change loaders** while data is fetched.
- **Inline status indicators** in tables or lists, next to rows that are still processing.

## Notes & Tips

- **Announce it properly:** `role="img"` and `aria-label="Loading"` give the SVG a name. If the spinner replaces content, put it inside a `role="status"` container (or use `aria-busy="true"` on the region that's loading) so screen readers are told something is happening.
- **Slow it down, don't stop it, for reduced motion:** a spinner that doesn't move can look frozen. A slower rotation still shows progress without fast movement. In the growing variant, the dash animation is switched off and the arc is held at a fixed length, so only the slow rotation remains. You could also swap either spinner for a "Loading…" text label.
- **Namespace the class:** a `<style>` inside an inline SVG applies to the **whole page**, not just that SVG. Use a specific class name, or move the rules into your normal stylesheet.
- **No `pathLength`?** Use the real circumference instead: with `r="20"`, a quarter arc is `stroke-dasharray="31.4 94.2"`.
- **Browser support:** the standalone `rotate` property works in every current browser (Chrome 104+, Firefox 72+, Safari 14.1+). For older browsers, use `transform: rotate(360deg)` in the keyframes instead.
- **Waiting for a reply?** For chat and other "someone is responding" states, [SVG Three-Dot Loading Indicator with Staggered Delays](/snippet/svg-three-dot-loader) builds three pulsing dots with the same `currentColor` colouring and reduced-motion handling.
- **Same dash trick on a rectangle:** [SVG Marching Ants Border for Drop Zones and Selections](/snippet/svg-marching-ants-border) animates `stroke-dashoffset` around a `<rect>`, using `pathLength` to make the dashes fit with no seam.
- **Keep it cheap:** rotating the `<svg>` is a transform, which the compositor can handle. Animating `stroke-dasharray` repaints the stroke each frame, which is fine for one small icon but adds up if you show many at once.

## Frequently Asked Questions

<Details summary="Why does the spinner need pathLength?">
  Without it, the dash values are in user units, so you'd have to work out the circle's circumference (`2πr`) and
  recalculate every time the radius changes. With `pathLength="100"`, `25 75` is always a quarter arc, whatever the
  radius, so you can resize the circle without touching the dash pattern.
</Details>

<Details summary="Why doesn't the spinner rotate around its centre in my project?">
  The rotation is applied to the `<svg>` element, which turns around its centre by default. If you put the animation on
  the `<circle>` instead, its `transform-origin` is the SVG's top-left corner, so it swings out of place. Either rotate
  the outer `<svg>`, or set `transform-box: fill-box` and `transform-origin: center` on the circle.
</Details>

<Details summary="How do I make the arc longer or shorter?">
  Change the first dash value and keep the two numbers adding up to 100, for example `50 50` for a half circle or `10 90`
  for a short tick. In the growing variant, the `75` in the keyframes is the longest the arc gets.
</Details>

<Details summary="Can I use it without an inline style block?">
  Yes. Move the `@keyframes` rule and the `.svg-spinner` rule into your normal stylesheet and keep only the `<svg>` and
  `<circle>` markup in the page. That also avoids the page-wide scope of a `<style>` element inside an SVG.
</Details>

## Key Takeaway

One `<circle>` with `pathLength="100"` and `stroke-dasharray="25 75"` gives you a quarter arc, and a `linear`, infinite `rotate` animation turns it into a spinner. Animate the dash pattern too for an arc that grows and shrinks. Either way it's a few lines of markup that scale cleanly, follow `currentColor`, and respect reduced motion.
